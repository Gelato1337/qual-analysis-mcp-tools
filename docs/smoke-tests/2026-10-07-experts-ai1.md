# First full run: 17 expert interviews, AI-only (2026-10-07)

Run `ai1` in the `experts` project (kept outside this repository). Data: the 17 Finnish expert
interviews behind Laato et al. (2023, *Information Systems Frontiers*); study brief in
`examples/amcis2025/intent.yaml` (the paper's RQ1 and RQ2 verbatim, no published results).
Claude Opus 5.5 in Claude Code 2.1.292, one isolated session per task; TypeDB 3.12.1.

`qls pipeline ai1 --auto --seed 1`: calibration on 3 random interviews (E11, E06, E17), the other
14 one session each in batches of 7, then themes, dimensions and revise. At every checkpoint the
policy `auto:approve-all` approved all codebook proposals as written and gave no answers.

## Contamination probes (before the run, no data, no tools)

- Asked for the paper's data structure, the model said it could not recall it.
- Asked to predict the dimensions from the brief alone, it produced much of the published
  structure (platform concentration, data and AI, automation, software in every industry) and a
  cultural-lag dimension. The brief and the model's priors alone get far; an analysis has to beat that.

## Findings about the pipeline

1. **Fragmentation instead of over-generalisation.** The agent kept each informant's idea as its own
   concept and almost never added evidence to an earlier interview's concept; cross-informant
   integration happened only at the themes stage. The calibration checkpoint asked exactly this
   ("keep the grain, or merge same-direction claims with add_evidence?"); the AI-only policy gives
   no answers, so the question went unanswered. This is the first thing a human calibration review
   should settle.
2. **The lifecycle-model part of the interviews is over-represented** (6 themes, most of one
   dimension), although the brief says to code it only where informants describe change.
3. **A cultural-lag dimension appeared**, as the brief-only probe predicted: possibly the lens
   speaking rather than the data.
4. **Pipeline bug, fixed:** calibration read E17 with `read_source` without `begin`, so the
   pipeline queued it again. Sources now count as coded if begun or given an interview memo.
