Stage: frame.

Set up the coding frame before any coding starts.

1. Orient: `intent()` (the research question, the `coding_frame` and the `theory_frame`),
   `method_guide()`, `ways_of_working()`, `guide("coding-frame")`, `status()`, `list_sources()`.
2. Create the guide categories from `coding_frame`, exactly as given, each with a definition that
   says what belongs and what does not.
3. Map the interview guide against the research question: for each part of the guide described in
   `intent()` (questions, material shown, parts asked for other purposes), propose one `scope` rule
   with `propose_codebook(kind="scope", ...)`: how answers to it count, and what does not count (the
   tool's description explains scope rules).
4. If the frame seems to miss something the research question needs, write a `method` memo about
   the intent. Do not add categories.
5. `checkpoint(summary, questions)` and stop.
